# 你好，我是章笑语 (Zhang Xiaoyu) 👋

> **“左手一指禅，敲出属于我们自己的世界线。”**  
> 把机器留给翻文件，把人留给历史、生活与想象。

我是章笑语，一名独立软件开发者，也是一名二级肢体残障开发者。

因为小脑损伤导致四肢协调困难，我写下所有代码、Mod 脚本和文档，依靠的都是**左手的一根手指**（“一指禅”）。我的成长求学经历曾被央视《朝闻天下》客户端和 CCTV-10 专题报道。感谢党和国家的高考残疾人延时政策，让我有机会考上大学学计算机，打破所谓的技术滤镜，看懂代码与 AI 底层。

大学毕业后，我跑了十几家面试，都因为打字速度慢被拒之门外；我也曾跌入过杀猪盘与网贷的绝境，是社区朋友们伸出援手把我拉出了泥潭。如今我选择全职做开源与独立开发——**长大了，不想啃老，只想靠自己的技术与双手，堂堂正正地养活自己。**

---

### 🕊️ 为什么我不再做《钢铁雄心 4》Mod 了？

熟悉我的朋友知道，我是**《TNO：东方红》**的创始人与初代组长（*2022 年后所有更新均由雾岛小枝领导的优秀团队共建完成*），也做过**《千禧黎明：红色之梦》**、**《革命的遗产 KX版》** 等子模组，全网巅峰累计有超过 **100,000+ 订阅**。

很多人问我为什么不继续主导做 Mod 了，我想坦诚聊聊原因：

1. **大环境与现实风险**：懂得都懂的大环境变化，继续高强度碰敏感题材风险太大。2024 年我已经去喝过一次茶了，不想再给家人和自己惹麻烦。
2. **心境变了**：走出抑郁症之后，我心态平和了很多。对网上的宏大叙事、站队辩论、传播意识形态逐渐脱敏，比起赛博键政，我更想回归真实的生活。
3. **“实在没活了”**：P 社引擎的自由度就那么大，受限于我个人的历史社科知识储备，继续硬编只会不可避免地滑向“猎奇”和怪力乱神。我不想为了噱头去写越来越荒诞的东西，我写不下去了。
4. **授人以渔，胜过自己当矿工**：与其我一个人在枯燥的脚本里耗尽热情，不如把我这 7 年“坐脚本牢”踩过的坑做成工具，**让人民群众自己去创造属于他们自己的世界线**。

### 🛠️ 我现在在做什么？

#### 1. 🤖 [夏语智能体 (Xia Agent)](https://xiavoiceagent.com)
> **“把 AI 发配去挖土豆，把人留给历史。”**

专为《钢铁雄心 4》及复杂工程打造的 **Windows 本地智能体工作台**。
* **痛点**：做 Mod 本来是为了构思历史，结果 80% 的时间在当 TXT 矿工——开 114514 个文件找 1919 个定义，漏个大括号查半天 error.log。对于正常人是折磨，对一指禅的我来说简直是刑讯。
* **特性**：本地优先、结合项目真实依赖层（游戏本体 + DLC + 父 Mod + 本地项目）、审查驱动（草稿 ➔ 差异对比 ➔ 诊断 ➔ 确认写入）。支持标准 MCP 与 `hoi4skill` 知识库。
* **技术底座**：Rust / .NET / WinUI 3 / 本地大模型（兼容 Ollama / LM Studio）/ 端侧视觉与 OCR。

#### 2. 🎮 独立游戏：《北极星往事》（开发中）
> **校园恋爱 × 制度运作 × 人生模拟**

很多恋爱模拟游戏里的感情像是发生在真空里，角色无缘无故地倒贴。我想做一款**让人物感情扎根于具体社会制度、工作收入与现实处境**的游戏。
* 玩家扮演生活在虚构集产主义社会里的普通人，经历大学、创业、求职、恋爱与冲突。
* 自研轻量引擎，深度支持 Mod 扩展，希望每个人都能在这个世界里写下自己的平行人生。
