## 代表项目

### 啊拼 / AI Quick Prompt

面向 Windows 用户的开源 AI 提示词工作台，采用 WinUI 3 + .NET 8 构建现代桌面体验，支持提示词优化、双语输出、模板库、Skill 工作流挂载、本地 OCR、OpenAI-compatible 模型接入与隐私友好的本地处理路径。

这个项目来自我对 AI 工具可达性和桌面效率的长期思考：让用户不必理解复杂的提示词工程，也能把粗糙想法转化为可执行、可复用、可迁移的高质量提示词。

项目地址：https://github.com/zhangxiaoyu66666/aping-AI-Quick-Prompt

### 夏语系列 AI 应用

独立开发中的 AI 伴侣与互动应用系列，探索端侧模型、桌面交互、情感化 UI 和长期陪伴式软件体验。

我希望它不只是一个聊天窗口，而是一个能理解上下文、尊重用户隐私、具备长期记忆与本地能力的个人 AI 软件系统。

### 新秩序：东方红 / The New Order: The East is Red

曾任 Hearts of Iron IV 大型模组《新秩序：东方红》（The New Order: The East is Red）前组长，负责或参与世界观设计、事件脚本、政治经济叙事与内容组织工作。

这个项目基于我对近现代政治史、地缘格局和宏观经济周期的长期兴趣，尝试在大战略游戏中构建更严谨、更有代入感的历史分支叙事。

## 技术方向

- Windows 原生桌面应用：WinUI 3、Fluent Design、Acrylic / Mica、WebView2

- 系统与性能：Rust、.NET、Tauri、原生 worker、端侧推理
- 用户体验：桌面效率工具、可达性设计、多语言本地化、隐私友好交互
- 内容系统：游戏事件脚本、世界观设计、政治经济叙事、历史分支推演
